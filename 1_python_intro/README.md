## Тема

Вступні заняття: налаштування середовища, початок роботи з Python та Markdown.

## Мета роботи

Налаштувати середовище роботи у VS Code, створити репозиторій GitHub і налаштувати інтеграцію з ним, написати першу програму на Python та створити звіт із використанням Markdown.

## Виконання роботи

1. Створено папку `1_python_intro` для файлів цієї роботи.
2. Створено програму [first_app.py](first_app.py), яка виводить ім’я, поточні дату й час та улюблене місто.
3. Створено Notebook [first_app.ipynb](first_app.ipynb) із кодом Python, Markdown-описом програми та окремою програмою-привітання, запропонованою Copilot.
4. Програму-привітання можна запустити в Notebook: введіть ім’я у запиті, і програма виведе персональне привітання.
