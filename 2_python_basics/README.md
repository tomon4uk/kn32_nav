## Мета роботи

Навчитися застосовувати основні конструкції мови Python, виконати приклади та за допомогою AI створити власні приклади, які демонструють особливості конструкцій Python.

## Виконання роботи

Приклади коду виконано в Jupyter Notebook [python_basics.ipynb](python_basics.ipynb). У Notebook є Markdown-комірки з поясненнями та кодові комірки з результатами виконання.

Розглянуто такі теми:

- базові типи даних: `str`, `int`, `float`, `list`, `dict`, `tuple`, `set`;
- вбудовані константи та ключові слова Python;
- вбудовані функції `abs()`, `len()` і `repr()`;
- цикли `for` та `while`;
- розгалуження `if` / `elif` / `else`;
- обробка помилок через `try` / `except` / `finally`;
- контекстний менеджер `with` для роботи з файлом;
- lambda-функції;
- додаткові приклади, створені за допомогою AI, і їхні результати.

У прикладі типів даних множина створюється як `{"ss", a + str(b)}`. Це потрібне перетворення, бо `a` є рядком, а `b` є цілим числом, і Python не дозволяє безпосередньо додати `str` до `int`.

## Результати

Усі кодові комірки Notebook виконано успішно. Перевірено виведення типів і структур даних, констант та ключових слів, результатів вбудованих функцій, циклів і розгалужень. Також продемонстровано перехоплення `ZeroDivisionError`, автоматичне закриття файлу контекстним менеджером і виклик lambda-функцій.

Окремий AI-приклад обчислює суму парних чисел від 1 до 10 за допомогою генератора списку та `sum()`; результат виконання — `30`.
